# João Victor — Online Résumé

A responsive, printable résumé website designed to present my experience, education, technical stack and selected software projects.

## Live version

**[View the online résumé](https://jhonyuusha.github.io/curriculum/)**

The page includes a dedicated A4 print stylesheet and can generate a PDF directly through the browser's print dialog.

## Positioning

The résumé is focused on junior backend and full-stack opportunities, highlighting:

- professional web development experience;
- Node.js and TypeScript backend development;
- REST APIs, authentication and relational databases;
- React-based frontend development;
- software architecture, tests and AI-assisted development practices.

## Tech stack

- Semantic HTML5
- CSS3 and responsive design
- JavaScript
- GitHub Pages
- Print-specific A4 layout
